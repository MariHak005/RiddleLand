# RiddleLand 🧩

An exploratory puzzle game built with Unity and C#. 

## About
RiddleLand is a group project developed during university. Players explore levels, solve riddles, and progress through the game.

## Tech Stack
- Unity (Game Engine)
- C# (Game Logic)

- Worked on game logic and feature implementation.
